# 市政道路施工封路方案协调与审批平台

源提示词编号：11。支持分段封路范围、施工阶段、绕行路线、车道收窄和临时设施的同一地图协作；检查相邻工程、救护通道、公交覆盖和绕行时延冲突；提供图层开关、路线绘制、阶段时间轴、条件会签、版本比较和公开通告包导出。

## 修订链模型

施工阶段内容修订、各方会签确认、公开通告共用一条连续编号链（R1…Rn），每条挂全量快照：

- **选择性失效**：每条意见带 `confirmedRev`。围挡几何、时间、控制条件（车道/疏导）或关联绕行一变更即生成新修订，只有锚点落在受影响阶段（含该阶段服务的绕行）上的“已接受”意见派生为“待重新确认”，其他单位不返工。
- **通告门槛**：通告只能在各阶段当前修订下不存在待处理/待重签/退回意见时生成；未确认阶段在预览中单列；通告本身是链上条目，正文标注“依据修订 Rn”，历史版本可查看、可下载。
- **离线合并**：离线期间本地修订继续保存，条目带来源 `clientId`；恢复联网后按共同基线前缀切分叉，服务端条目并入，本地内容修订以结构化补丁重放，会签动作按意见 id 取最新并重锚 `confirmedRev`，编号重排连续。
- **旧数据迁移**：无修订号的旧 localStorage（`yy54-road-scheme-v1`）首次加载时整体迁移为初始修订 R1，全部意见锚定 R1，写入 `yy54-road-scheme-v2`。
